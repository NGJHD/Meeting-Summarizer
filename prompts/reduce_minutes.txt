# Minutes — {{MEETING_NAME}}
*Meeting Duration: {{DURATION}}*

## Participants
One line per speaker label: the label, the inferred name if the evidence supports one,
and your confidence (high / medium / low). Where there is no evidence, write
"no name evidence".

## Decisions
One line each, with its (HH:MM:SS) timestamp. Only things actually decided. If the
meeting decided nothing, write "No decisions were recorded."

## Action Items
Markdown checkboxes, grouped under a bold owner heading. Format each as:

- [ ] **Owner** — task — deadline — (HH:MM:SS)

Use `Unassigned` where no owner was stated, and omit the deadline field entirely where
none was given. NEVER invent an owner or a deadline. An action item reading
"Unassigned — chase the vendor quote — (01:12:04)" is a correct and useful output. A
fabricated owner is a serious failure, because the reader will act on it and the named
person will not be expecting it.

## Discussion Record
By topic, using short topic sub-headings (###). Two to four bullets each. Bullets, not
prose.

## Open Questions
One line each. Questions raised and not answered.

## Attribution Notes
